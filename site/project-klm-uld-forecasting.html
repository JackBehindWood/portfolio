Forecasting system for unit load device (ULD) availability, built end to end in Python (data pipeline to scikit-learn model) at the Cargo Control Center, as the baseline for later allocation work.

Approach

  • Pipeline from raw booking and inventory data to a forecast per route and day, in Python.
  • Prophet time-series model plus a scikit-learn model on booking-derived features, combined with Ridge regression and tuned with Bayesian optimisation.
  • Features built from booking velocity and acceleration, lags, rolling averages and holiday and event indicators.
  • Wrote the mathematical design for ULD allocation (the content is confidential).

Limits

A baseline, not a finished allocation system. The data and results are confidential and not shown.
