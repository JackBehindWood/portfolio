Privacy policy: Career Hub

Last updated 10 November 2026

Career Hub is a personal tool. It is used only by its owner, Jack Agterdenbos, to read his own LinkedIn profile data through LinkedIn's Member Data Portability API, so that he can check and improve his own CV and profile text.

What data the app accesses

Only the data of the LinkedIn member who authorises it (the owner): profile, positions, skills and education.

How the data is used

It is saved as files on the owner's own computer. It is not sold, shared, published or sent to any third party, and it is not stored on any server run by the app.

Access tokens

The access token is stored only on the owner's computer, is never shared, and is deleted when it expires or when access is revoked.

Other users

The app is not offered to the public and collects no data from anyone else.

Revoking access and deletion

The owner can revoke access at any time in LinkedIn under Settings and Privacy, and can delete the local files at any time.
