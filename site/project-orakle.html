Orakle World Cup prediction tool

A prediction tool for the Scorito World Cup 2026 game: a tournament simulation, an ensemble of three models and a web dashboard.

ResultI won our pool with it.

  • Python
  • FastAPI
  • XGBoost
  • React
  • Recharts

Orakle predicts the 2026 World Cup for Scorito, a Dutch prediction game. It simulates the whole tournament with a Monte Carlo method, combines Dixon-Coles, Poisson regression and XGBoost models in a weighted ensemble, and ranks every prediction by expected Scorito points instead of by the most likely outcome. A FastAPI backend serves a React and Recharts dashboard with six pages: overview, matches, groups, knockouts, top scorers and model health.

Status

Built and used by one developer for a friends' prediction pool, which Jack won. The repository is private, available on request.

Approach

  • Simulation: a Monte Carlo simulation of the whole tournament.
  • Models: an ensemble of Dixon-Coles, Poisson regression and XGBoost models.
  • Decision: every prediction is ranked by its expected Scorito points, not by the most likely outcome.
  • Software: a FastAPI backend with a scheduled data refresh, and a React and Recharts dashboard with six pages (overview, matches, groups, knockouts, top scorers, model health).

Limits

A personal tool for one prediction game. No accuracy results are reported.
